# 🚀 Instruções para Configuração do Projeto

## Como iniciar o projeto

1. **Instale as dependências**  
   Execute o seguinte comando no terminal:  
   npm install  
   # ou  
   npm i  

2. **Configure e inicie o banco de dados e a aplicação**  
   Para rodar o banco de dados e iniciar a aplicação, use o comando:  
   docker-compose up
